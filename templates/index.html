NUESTRO PROYECTO

Quiénes somos

FitZone Store es un proyecto web orientado a la presentación y gestión de productos relacionados con el entrenamiento físico, el deporte y el bienestar personal.

Nuestro objetivo es integrar diseño, usabilidad y tecnología en una solución funcional desarrollada con herramientas como HTML5, CSS3, Bootstrap, JavaScript, Python, Flask y bases de datos relacionales.

La aplicación permite aplicar de manera práctica los conocimientos adquiridos durante la asignatura Desarrollo de Aplicaciones Web.
