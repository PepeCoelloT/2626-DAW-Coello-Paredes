Bienvenidos

FitZone Store es una página web dedicada a presentar productos, accesorios y artículos relacionados con el entrenamiento físico.

Aquí podrás conocer diferentes productos deportivos, consultar su disponibilidad y registrar nuevos artículos de manera dinámica.

Quiénes somos

FitZone Store es un proyecto web enfocado en ofrecer productos útiles para el entrenamiento físico y el bienestar personal.

Nuestro objetivo es brindar a los usuarios una alternativa práctica para conocer artículos deportivos como bandas elásticas, mancuernas, colchonetas, botellas deportivas, guantes de gimnasio y ropa deportiva.

Como proyecto académico, esta aplicación permite aplicar conocimientos de HTML5, CSS3, Bootstrap, JavaScript, Python y Flask mediante una estructura organizada, dinámica y responsiva.
