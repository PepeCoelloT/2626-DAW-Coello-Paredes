NUESTRO PROYECTO

Quiénes somos

FitZone Store es un proyecto web orientado a la presentación y gestión de productos relacionados con el entrenamiento físico, el deporte y el bienestar personal.

Nuestro objetivo es integrar diseño, usabilidad y tecnología en una solución desarrollada con HTML5, CSS3, Bootstrap, JavaScript, Python, Flask y MySQL.

El proyecto permite aplicar de manera práctica los conocimientos desarrollados durante la asignatura Desarrollo de Aplicaciones Web.
